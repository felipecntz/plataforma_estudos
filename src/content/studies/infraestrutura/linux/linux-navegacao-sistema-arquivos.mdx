## Ideia central

<DefinitionBlock title="Tudo começa pelo caminho" text="No Linux, arquivos, diretórios, dispositivos e configurações aparecem dentro de uma árvore que começa em /. Saber navegar evita executar comandos no lugar errado." />

## Comandos principais

```bash
pwd              # diretório atual
ls               # lista arquivos
ls -la           # lista detalhes e ocultos
ls -lh           # tamanhos legíveis
cd /etc          # entra em /etc
cd ..            # sobe um nível
cd -             # volta ao diretório anterior
cd ~             # vai para a home do usuário
```

## Caminhos absolutos e relativos

```bash
/var/log/syslog      # caminho absoluto
../backup/app.log    # caminho relativo
./script.sh          # arquivo no diretório atual
```

Caminho absoluto começa em `/`. Caminho relativo depende de onde você está.

## Diretórios comuns

| Diretório | Uso comum |
| --- | --- |
| `/etc` | arquivos de configuração |
| `/var` | logs, filas, caches e dados variáveis |
| `/home` | diretórios dos usuários |
| `/tmp` | arquivos temporários |
| `/usr` | programas e bibliotecas |
| `/bin` e `/sbin` | comandos essenciais |
| `/opt` | softwares instalados à parte |

<ExampleBlock title="Operação rápida" text="Para investigar logs, rode cd /var/log, depois ls -lh para listar arquivos com tamanhos fáceis de ler." />

<TipBlock title="Confirme antes de agir" text="Use pwd e ls antes de mover, apagar ou editar arquivos. Esse hábito simples evita acidentes caros." />
