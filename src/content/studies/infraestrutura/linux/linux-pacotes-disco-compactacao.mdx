## Ideia central

<DefinitionBlock title="Operar sistema é medir antes de mudar" text="Instalar pacotes, limpar disco e compactar arquivos são tarefas comuns. O bom fluxo é consultar estado, agir com escopo claro e conferir o resultado." />

## Pacotes

Debian e Ubuntu:

```bash
sudo apt update
sudo apt install nginx
sudo apt remove nginx
apt search nginx
```

Fedora, Rocky e similares:

```bash
sudo dnf install nginx
sudo dnf remove nginx
dnf search nginx
```

Alpine:

```bash
sudo apk add curl
sudo apk del curl
apk search curl
```

## Disco

```bash
df -h
du -sh /var/log
du -h --max-depth=1 /var | sort -h
lsblk
```

`df` mostra sistemas de arquivos. `du` mede arquivos e diretórios.

## Encontrar arquivos grandes

```bash
find /var -type f -size +100M
find /var/log -type f -mtime +30
```

<WarningBlock title="Não apague logs sem entender" text="Logs podem ser importantes para auditoria e diagnóstico. Antes de remover, confirme retenção, serviço dono e política do ambiente." />

## Compactar e extrair

```bash
tar -czf backup.tar.gz /opt/app
tar -xzf backup.tar.gz
zip -r backup.zip pasta/
unzip backup.zip
gzip arquivo.log
gunzip arquivo.log.gz
```

## Exemplo de operação

```bash
df -h
du -sh /var/log
sudo tar -czf /tmp/logs.tar.gz /var/log
ls -lh /tmp/logs.tar.gz
```

<ExampleBlock title="Backup rápido de logs" text="Antes de limpar uma pasta de logs, compacte uma cópia em /tmp ou em um diretório de backup definido pelo ambiente." />

<TipBlock title="Instale só o necessário" text="Em servidores, pacote a mais é superfície a mais. Prefira ferramentas úteis, conhecidas e justificadas pela operação." />
