## Ideia central

<DefinitionBlock title="Investigar é filtrar" text="Em Linux, muitos problemas aparecem em arquivos de texto: logs, configurações e saídas de comandos. Saber filtrar é mais importante que decorar tudo." />

## Ver conteúdo

```bash
cat arquivo.txt
less arquivo.txt
head -20 arquivo.txt
tail -50 arquivo.txt
tail -f app.log
```

`less` é melhor para arquivos grandes. `tail -f` acompanha logs em tempo real.

## Buscar texto com grep

```bash
grep "ERROR" app.log
grep -i "timeout" app.log
grep -n "listen" nginx.conf
grep -r "DB_HOST" /etc
```

Opções úteis:

| Opção | Uso |
| --- | --- |
| `-i` | ignora maiúsculas e minúsculas |
| `-n` | mostra número da linha |
| `-r` | busca recursivamente |
| `-v` | inverte o filtro |

## Buscar arquivos com find

```bash
find /var/log -type f -name "*.log"
find . -type f -size +100M
find . -type f -mtime -1
```

## Pipes

```bash
ps aux | grep nginx
cat app.log | grep ERROR | wc -l
history | tail -20
```

O pipe `|` conecta comandos. A saída do primeiro vira entrada do segundo.

## Ordenar e contar

```bash
wc -l app.log
sort nomes.txt
sort nomes.txt | uniq
sort nomes.txt | uniq -c
```

<ExampleBlock title="Contar erros em log" text="grep ERROR app.log | wc -l filtra linhas com ERROR e conta quantas linhas sobraram." />

<TipBlock title="Prefira less em arquivo grande" text="cat em arquivo enorme joga tudo na tela. less permite navegar, buscar com /texto e sair com q." />
