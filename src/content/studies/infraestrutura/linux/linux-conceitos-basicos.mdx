## Ideia central

<DefinitionBlock title="Linux é infraestrutura na prática" text="Linux é uma família de sistemas operacionais muito usada em servidores, nuvem, containers, automação e segurança. Para operar Linux bem, o terminal é o caminho mais importante." />

## Conceitos rápidos

| Conceito | Resumo |
| --- | --- |
| Kernel | núcleo que conversa com hardware e recursos do sistema |
| Distribuição | Linux empacotado com ferramentas, instalador e gerenciador de pacotes |
| Shell | programa que interpreta comandos |
| Terminal | janela ou sessão onde você digita comandos |
| Root | usuário administrador do sistema |

## Primeiros comandos

```bash
pwd          # mostra o diretório atual
whoami       # mostra o usuário atual
hostname     # mostra o nome da máquina
date         # mostra data e hora
clear        # limpa a tela
history      # lista comandos recentes
```

## Ajuda no próprio sistema

```bash
man ls
ls --help
apropos network
```

`man` abre o manual. `--help` costuma mostrar uma ajuda curta. `apropos` pesquisa comandos relacionados a um termo.

<ExampleBlock title="Operação simples" text="Para descobrir onde você está e quem está usando a sessão, rode pwd e whoami. Em servidor remoto, isso evita agir no lugar errado." />

<TipBlock title="Comece lendo antes de alterar" text="Em infraestrutura, prefira comandos de consulta primeiro. Entenda o estado atual antes de instalar, mover, apagar ou reiniciar serviços." />
