## Ideia central

<DefinitionBlock title="Django e um framework web completo" text="Django permite construir uma aplicacao web com rotas, views, templates, ORM, migrations, formularios, autenticacao, admin, seguranca e organizacao por apps." />

Em um projeto monolito, a aplicacao principal entrega quase tudo: HTML, regras de negocio, banco de dados, formularios, login, admin, arquivos estaticos e deploy. Isso e muito bom para sistemas internos, CRUDs, portais, backoffices e produtos que ainda nao precisam de arquitetura distribuida.

## Fluxo da requisicao

```text
Navegador
  -> URL do Django
  -> View
  -> Model/ORM
  -> Banco de dados
  -> Template HTML
  -> Resposta para o navegador
```

Em Django, a view nao e a tela. A view e a funcao ou classe que recebe a requisicao e decide o que devolver. A tela costuma ser o template.

## MTV

| Peça | Papel | Comparacao mental |
| --- | --- | --- |
| Model | dados, tabelas, relacoes e regras proximas do banco | o que existe |
| Template | HTML final com variaveis e blocos | como aparece |
| View | coordena request, regra e response | o que acontece |
