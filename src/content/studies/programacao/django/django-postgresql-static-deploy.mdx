## PostgreSQL

Instale o driver:

```bash
pip install "psycopg[binary]"
```

Configuracao simples:

```python
DATABASES = {
    "default": {
        "ENGINE": "django.db.backends.postgresql",
        "NAME": "meu_banco",
        "USER": "meu_usuario",
        "PASSWORD": "minha_senha",
        "HOST": "localhost",
        "PORT": "5432",
    }
}
```

Em projeto real, use variaveis de ambiente para senhas e hosts.

## Static e media

```python
STATIC_URL = "static/"
STATIC_ROOT = BASE_DIR / "staticfiles"
STATICFILES_DIRS = [BASE_DIR / "static"]

MEDIA_URL = "media/"
MEDIA_ROOT = BASE_DIR / "media"
```

Coletar arquivos estaticos:

```bash
python manage.py collectstatic
```

`static` e do projeto. `media` e upload de usuario.

## Comandos essenciais

| Comando | Uso |
| --- | --- |
| `python manage.py runserver` | servidor local |
| `python manage.py makemigrations` | gera migrations |
| `python manage.py migrate` | aplica migrations |
| `python manage.py createsuperuser` | cria admin |
| `python manage.py shell` | shell Django |
| `python manage.py dbshell` | shell do banco |
| `python manage.py test` | testes |
| `python manage.py collectstatic` | arquivos estaticos |
| `python manage.py check --deploy` | checagens de producao |

## Deploy mental

Fluxo comum:

```bash
python manage.py check --deploy
python manage.py migrate
python manage.py collectstatic --noinput
gunicorn config.wsgi:application
```

Arquitetura comum:

- Nginx na frente;
- Gunicorn ou uWSGI rodando Django;
- PostgreSQL como banco;
- static files servidos pelo Nginx;
- variaveis de ambiente;
- logs e backups configurados.

## Seguranca basica

- `DEBUG = False` em producao;
- configure `ALLOWED_HOSTS`;
- proteja `SECRET_KEY`;
- use HTTPS;
- nao versione senha;
- valide permissoes nas views;
- rode `check --deploy`;
- faca backup antes de migrations sensiveis.

<WarningBlock title="SQLite para aprender, PostgreSQL para publicar" text="SQLite e ótimo no inicio. Para sistemas publicados com concorrencia, PostgreSQL costuma ser mais robusto." />

<TipBlock title="Checklist antes de subir" text="Banco configurado, migrations aplicadas, static coletado, DEBUG false, ALLOWED_HOSTS correto e senha fora do codigo." />
