## Operadores aritméticos

| Operador | Operação | Exemplo | Resultado |
| --- | --- | --- | --- |
| `+` | soma | `7 + 3` | `10` |
| `-` | subtração | `7 - 3` | `4` |
| `*` | multiplicação | `7 * 3` | `21` |
| `/` | divisão real | `7 / 2` | `3.5` |
| `//` | divisão inteira | `7 // 2` | `3` |
| `%` | resto | `7 % 2` | `1` |
| `**` | potência | `2 ** 3` | `8` |

```python
preco = 100
desconto = 15
preco_final = preco - desconto

dobro = preco * 2
quadrado = 5 ** 2
```

## Prioridade das operações

Python respeita ordem de prioridade. Parênteses deixam a intenção explícita.

```python
resultado_1 = 2 + 3 * 4      # 14
resultado_2 = (2 + 3) * 4    # 20
```

<TipBlock title="Use parênteses para comunicar" text="Mesmo quando Python já sabe a prioridade, parênteses podem deixar seu raciocínio mais fácil de ler." />

## Operações com strings

Alguns operadores mudam de sentido conforme o tipo.

```python
nome = "Py" + "thon"
risada = "ha" * 3

print(nome)    # Python
print(risada)  # hahaha
```

`+` concatena strings. `*` repete uma string quando usado com inteiro.

## Comparações

Comparações sempre devolvem `True` ou `False`.

```python
idade = 20

print(idade >= 18)  # True
print(idade == 21)  # False
```

Não confunda `=` com `==`. O primeiro atribui; o segundo compara.

<WarningBlock title="Atribuição não é comparação" text="idade = 18 guarda o valor 18. idade == 18 pergunta se idade é igual a 18." />

## Operadores lógicos

`and`, `or` e `not` combinam condições.

```python
idade = 20
tem_documento = True

pode_entrar = idade >= 18 and tem_documento
precisa_ajuda = idade < 18 or not tem_documento
```

- `and`: todas as condições precisam ser verdadeiras;
- `or`: pelo menos uma condição precisa ser verdadeira;
- `not`: inverte o valor lógico.
