## Ideia central

<DefinitionBlock title="Condicional escolhe caminho" text="Uma condicional permite executar um bloco de código apenas quando uma condição é verdadeira. É assim que o programa deixa de ser uma linha reta e passa a tomar decisões." />

## if, elif e else

Python avalia as condições de cima para baixo e executa apenas o primeiro bloco compatível.

```python
nota = 8.5

if nota >= 9:
    conceito = "Excelente"
elif nota >= 7:
    conceito = "Aprovado"
else:
    conceito = "Em recuperação"

print(conceito)
```

`if` abre a primeira condição. `elif` testa alternativas. `else` cobre o caso restante.

## Ordem das condições

A ordem importa. Coloque condições mais específicas antes de condições mais amplas.

```python
idade = 70

if idade >= 60:
    print("Idoso")
elif idade >= 18:
    print("Adulto")
```

Se a regra de adulto viesse antes, uma pessoa de 70 anos seria classificada como adulta antes de chegar ao teste de idoso.

## Valores verdadeiros e falsos

Além de `False`, valores como `0`, `0.0`, `""`, `[]`, `()` e `{}` são considerados falsos em contexto lógico.

```python
nome = ""

if nome:
    print(f"Olá, {nome}!")
else:
    print("Nome não informado.")
```

Essa leitura é comum para verificar se uma coleção ou string possui conteúdo.

## Expressão condicional

Quando há apenas dois resultados simples, dá para usar uma forma curta:

```python
idade = 20
status = "adulto" if idade >= 18 else "menor de idade"
```

<WarningBlock title="Não compacte regra grande" text="Se a decisão tiver muitas condições, efeitos ou etapas, use if, elif e else em blocos. Código curto demais pode ficar mais difícil de entender." />

## Condições compostas

Use `and`, `or` e `not` para combinar regras.

```python
idade = 20
tem_documento = True

if idade >= 18 and tem_documento:
    print("Entrada liberada")
```

<TipBlock title="Leia como frase" text="Uma boa condição costuma soar bem em português: se idade é maior ou igual a 18 e tem documento, então liberar entrada." />
