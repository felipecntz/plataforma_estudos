## Ideia central

<DefinitionBlock title="Função dá nome a um raciocínio" text="Uma função reúne instruções que cumprem uma responsabilidade. Ela evita repetição, melhora a leitura e facilita testar partes pequenas do programa." />

## Criando função com def

```python
def calcular_media(notas):
    if not notas:
        return 0.0
    return sum(notas) / len(notas)


media = calcular_media([8.0, 7.5, 9.0])
print(media)
```

`notas` é parâmetro na definição. A lista `[8.0, 7.5, 9.0]` é argumento na chamada.

## return

`return` encerra a função e devolve um resultado.

```python
def dobro(numero):
    return numero * 2
```

Sem `return` explícito, a função devolve `None`.

## Argumentos posicionais, nomeados e padrões

```python
def apresentar(nome, saudacao="Olá"):
    return f"{saudacao}, {nome}!"


print(apresentar("Iara"))
print(apresentar(nome="Iara", saudacao="Bem-vinda"))
```

Valores padrão são úteis para comportamentos comuns.

<WarningBlock title="Cuidado com padrão mutável" text="Evite listas e dicionários como valores padrão de parâmetros. Use None e crie a coleção dentro da função quando precisar." />

## Built-in functions

Built-ins são funções disponíveis sem importar nada.

| Função | Finalidade |
| --- | --- |
| `print()` | exibir valores |
| `input()` | ler texto digitado |
| `len()` | contar itens |
| `type()` | inspecionar tipo |
| `int()`, `float()`, `str()`, `bool()` | converter ou criar valores |
| `sum()`, `min()`, `max()` | agregar números |
| `round()` | arredondar |
| `range()` | produzir intervalos |
| `enumerate()` | percorrer com índice |
| `zip()` | combinar iteráveis |
| `sorted()` | ordenar |

Não use nomes como `list`, `str`, `sum` ou `max` para variáveis. Isso esconde a função original no escopo atual.

## Lambda

`lambda` cria uma função anônima de uma expressão só.

```python
dobrar = lambda numero: numero * 2

resultado = dobrar(5)

print(resultado)
```

Nesse exemplo, `dobrar` recebe uma função curta que pega `numero` e devolve `numero * 2`. Quando chamamos `dobrar(5)`, o resultado é `10`.

Lambda também aparece bastante como argumento de outras funções:

```python
pessoas = [
    {"nome": "Ivo", "idade": 31},
    {"nome": "Eva", "idade": 24},
]

por_idade = sorted(pessoas, key=lambda pessoa: pessoa["idade"])
```

Nesse segundo caso, a lambda informa qual campo deve orientar a ordenação.

<ExampleBlock title="Quando usar lambda" text="Use lambda quando a regra for curta e aparecer como argumento de outra função. Se precisar de várias linhas ou nome próprio, use def." />

<TipBlock title="Uma função, uma responsabilidade" text="Prefira funções pequenas que recebem dados e devolvem resultados. Nomes como calcular_media e validar_senha comunicam intenção." />
