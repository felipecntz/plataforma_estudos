## Ideia central

<DefinitionBlock title="for percorre iteráveis" text="O for visita cada item de uma sequência ou coleção. Ele é ideal quando a intenção é processar elementos já existentes." />

## Percorrendo listas

```python
nomes = ["Ana", "Caio", "Luz"]

for nome in nomes:
    print(f"Olá, {nome}!")
```

A cada volta, `nome` recebe um item da lista.

## Percorrendo strings

Strings também são iteráveis:

```python
for letra in "Python":
    print(letra)
```

## range

`range()` gera números. O limite final não entra.

```python
for numero in range(1, 6):
    print(numero)  # 1, 2, 3, 4, 5
```

Também dá para informar passo:

```python
for numero in range(0, 10, 2):
    print(numero)  # 0, 2, 4, 6, 8
```

## enumerate

Use `enumerate()` quando precisar do índice e do valor.

```python
notas = [8.0, 7.5, 9.0]

for indice, nota in enumerate(notas, start=1):
    print(f"Prova {indice}: {nota}")
```

Isso evita criar e atualizar um contador manual.

## zip

`zip()` percorre duas ou mais sequências em paralelo.

```python
nomes = ["Ana", "Beto", "Clara"]
notas = [8.0, 7.5, 9.0]

for nome, nota in zip(nomes, notas):
    print(nome, nota)
```

## Compreensões de lista

Uma compreensão cria uma nova lista a partir de um percurso.

```python
quadrados = [numero ** 2 for numero in range(1, 6)]
pares = [numero for numero in range(10) if numero % 2 == 0]
```

Use quando a transformação for curta e legível.

<ExampleBlock title="for ou while?" text="Use for para processar cada nota de uma lista. Use while para continuar pedindo uma nota até o usuário informar um valor válido." />

<TipBlock title="A pergunta guia" text="Se você já tem uma coleção para percorrer, pense primeiro em for. Se você está esperando uma condição mudar, pense em while." />
