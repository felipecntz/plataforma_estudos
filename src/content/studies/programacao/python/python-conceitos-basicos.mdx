## Ideia central

<DefinitionBlock title="Python prioriza clareza" text="Python é uma linguagem de programação de alto nível e propósito geral. Ela foi desenhada para deixar o código legível, direto e próximo da forma como descrevemos um problema em linguagem natural." />

Python é muito usada porque junta duas qualidades difíceis de encontrar ao mesmo tempo: é amigável para quem está começando e poderosa o suficiente para trabalhos profissionais. Ela aparece em scripts simples, análise de dados, inteligência artificial, automação, aplicações web, testes, ciência, educação e ferramentas internas de empresas.

## História e fundador

Python foi criada por **Guido van Rossum**, programador neerlandês, no fim dos anos 1980. A primeira versão pública saiu em **1991**. O nome não veio da cobra, mas do grupo de comédia britânico *Monty Python*, uma pista simpática sobre a cultura da linguagem: clareza, pragmatismo e um pouco de leveza.

Com o tempo, Python passou a ser mantida de forma aberta, com participação da comunidade e apoio da Python Software Foundation. Esse ecossistema aberto ajudou a linguagem a crescer em universidades, empresas, pesquisa científica e comunidades de tecnologia.

## Por que Python teve tanto impacto

Python reduziu a distância entre "ter uma ideia" e "criar um programa que funciona". Em vez de obrigar o iniciante a lidar cedo com muitos detalhes de memória, compilação e sintaxe pesada, ela permite focar primeiro no raciocínio.

Isso não significa que Python seja superficial. A mesma linguagem usada para escrever um primeiro `print()` também sustenta automações de produção, pipelines de dados, modelos de machine learning e serviços web.

<ExampleBlock title="Exemplo de primeiro contato" text="print('Olá, mundo!') é suficiente para pedir ao Python que mostre uma mensagem. A ideia é simples: chamar uma função e passar um texto para ela." />

## O que dá para fazer com Python

- automatizar arquivos, pastas, planilhas, relatórios e tarefas repetitivas;
- analisar, limpar e visualizar dados;
- criar modelos de inteligência artificial e aprendizado de máquina;
- desenvolver aplicações web usando frameworks externos;
- escrever testes automatizados;
- criar scripts de linha de comando;
- integrar sistemas e consumir serviços da internet;
- criar protótipos rapidamente.

## O que Python não resolve sozinho

Python não é a melhor resposta para tudo. Interfaces móveis nativas, jogos com gráficos pesados, sistemas embarcados muito restritos e trechos que exigem controle extremo de memória podem pedir outras linguagens ou bibliotecas especializadas.

<WarningBlock title="Linguagem boa não dispensa lógica" text="Python facilita a escrita, mas programar continua exigindo decompor problemas, testar hipóteses, lidar com erros e nomear bem as ideias." />

## Modelo mental

Pense em Python como uma caixa de ferramentas para transformar dados em resultado. Você escreve instruções, guarda valores em variáveis, usa operadores para calcular, coleções para organizar, condicionais para decidir, laços para repetir, funções para reaproveitar e classes para modelar entidades quando isso fizer sentido.
