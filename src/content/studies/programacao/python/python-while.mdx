## Ideia central

<DefinitionBlock title="while repete por condição" text="O while executa um bloco enquanto uma condição for verdadeira. Ele é indicado quando você não sabe exatamente quantas repetições serão necessárias." />

## Estrutura básica

```python
contador = 1

while contador <= 5:
    print(contador)
    contador += 1
```

O bloco roda enquanto `contador <= 5`. A linha `contador += 1` é essencial, porque altera o valor usado na condição.

<WarningBlock title="Cuidado com laço infinito" text="Se nada dentro do while muda a condição de saída, o programa pode repetir para sempre." />

## Exemplo com senha

```python
tentativas = 0
senha = ""

while senha != "python" and tentativas < 3:
    senha = input("Senha: ")
    tentativas += 1

if senha == "python":
    print("Acesso liberado")
else:
    print("Limite de tentativas atingido")
```

Aqui o laço para em duas situações: a senha correta aparece ou o limite de tentativas é atingido.

## break

`break` encerra o laço imediatamente.

```python
while True:
    comando = input("Digite sair para encerrar: ")

    if comando == "sair":
        break

    print(f"Você digitou: {comando}")
```

`while True` cria uma repetição teoricamente infinita, mas o `break` define uma saída explícita.

## continue

`continue` pula o restante da repetição atual e volta para o teste da condição.

```python
numero = 0

while numero < 6:
    numero += 1

    if numero == 3:
        continue

    print(numero)
```

O número 3 não é impresso, porque aquela volta foi pulada.

<ExampleBlock title="Quando usar while" text="Use while para continuar pedindo uma nota até que o usuário digite um valor válido, ou para repetir uma operação até uma condição de parada acontecer." />
