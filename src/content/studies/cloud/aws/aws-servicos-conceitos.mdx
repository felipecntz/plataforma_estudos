## Ideia central

<DefinitionBlock title="AWS é um conjunto de blocos de arquitetura" text="A Amazon Web Services oferece serviços para identidade, rede, computação, armazenamento, bancos, segurança, observabilidade e custos. O estudo fica mais claro quando cada serviço importante ganha sua própria página." />

Esta página é apenas o mapa de orientação. Os serviços principais foram separados para evitar uma revisão longa demais em uma única tela. A sequência recomendada é: fundamentos de cloud, visão geral da AWS, IAM, EC2, S3, RDS e Lambda.

## Conceitos que vêm antes dos serviços

| Conceito | O que significa |
| --- | --- |
| Conta AWS | limite administrativo e financeiro onde recursos são criados |
| Região | localização geográfica, como `us-east-1` ou `sa-east-1` |
| Availability Zone | datacenter isolado dentro de uma região |
| IAM | identidade, permissões, roles e políticas |
| VPC | rede virtual privada onde muitos recursos se conectam |
| ARN | identificador único de recursos AWS |
| Tags | etiquetas para custo, ambiente, dono e finalidade |

<TipBlock title="Ordem mental" text="Antes de pensar em servidor, pense em conta, região, identidade e rede. Muita arquitetura ruim nasce porque esses fundamentos ficam para depois." />

## Sequência de estudo sugerida

| Ordem | Tópico | Pergunta principal |
| --- | --- | --- |
| 1 | IAM | Quem pode fazer o quê? |
| 2 | EC2 | Quando preciso controlar um servidor? |
| 3 | S3 | Como guardar arquivos e objetos com segurança? |
| 4 | RDS | Quando usar banco relacional gerenciado? |
| 5 | Lambda | Quando executar código sem servidor fixo? |

<ExampleBlock title="Exemplo de arquitetura pequena" text="Uma aplicação web pode ter usuários e roles no IAM, servidores EC2 em subnets privadas, imagens no S3, banco PostgreSQL no RDS e funções Lambda para tarefas assíncronas." />

## O que fica para depois

Depois da base, avance para VPC em detalhe, Load Balancer, Auto Scaling, CloudFront, Route 53, CloudWatch, CloudTrail, KMS, Secrets Manager, DynamoDB, ECS/EKS e CloudFormation. Esses temas também devem virar páginas próprias quando o conteúdo crescer.

<WarningBlock title="Erro comum" text="Tentar decorar uma lista gigante de serviços. O melhor estudo é entender a função de cada família e aprofundar um serviço por página." />

## Resumo de revisão

AWS deve ser estudada por blocos. IAM cuida de identidade e permissão. EC2 entrega servidores virtuais. S3 guarda objetos. RDS opera bancos relacionais. Lambda executa funções por evento. A visão geral mostra o caminho, mas cada serviço importante precisa de página própria com resumo e mapa mental.
