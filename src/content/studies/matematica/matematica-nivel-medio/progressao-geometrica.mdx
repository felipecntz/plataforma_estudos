## O que define uma progressão geométrica

<DefinitionBlock title="PG é uma sequencia de variacao multiplicativa" text="Cada termo, a partir do segundo, é obtido multiplicando o anterior por uma razão constante. Ela modela fenômenos que crescem ou diminuem por fator ou percentual fixo." />

Na sequência `3, 6, 12, 24, ...`, cada termo é o anterior multiplicado por `2`. Portanto, `q = 2`.

<FormulaBlock
  name="Razao da PG"
  expression="q=\frac{a_n}{a_{n-1}}"
  description="A razão é o quociente entre um termo e seu antecessor, desde que o antecessor não seja zero."
  variables={[
    { label: "q", meaning: "fator multiplicativo constante" },
    { label: "aₙ", meaning: "termo atual" },
    { label: "aₙ₋₁", meaning: "termo anterior" }
  ]}
  example="Em 81, 27, 9, 3, temos q = 27/81 = 1/3."
  note="Confira a razão em mais de um par de termos."
  mistake="Subtrair termos consecutivos; isso encontra a razão de uma PA, não de uma PG."
/>

## Termo geral

<FormulaBlock
  name="Termo geral da PG"
  expression="a_n=a_1q^{n-1}"
  description="Até a posição n, a razão foi aplicada n - 1 vezes ao primeiro termo."
  variables={[
    { label: "aₙ", meaning: "termo da posicao n" },
    { label: "a₁", meaning: "primeiro termo" },
    { label: "q", meaning: "razao da PG" },
    { label: "n", meaning: "posicao procurada" }
  ]}
  example="Na PG 5, 15, 45, ..., a₆ = 5 × 3⁵ = 1.215."
  note="Também vale aₙ = aₖq^(n-k) ao usar outro termo como referência."
  mistake="Usar qⁿ; entre a primeira e a n-ésima posição existem n - 1 multiplicações."
/>

## Comportamento da sequência

O valor de `q` ajuda a prever a PG:

- `q > 1`: os módulos crescem quando o primeiro termo é não nulo;
- `0 < q < 1`: os termos positivos diminuem e se aproximam de zero;
- `q = 1`: todos os termos são iguais;
- `q = 0`: a partir do segundo termo, todos são zero;
- `q < 0`: os sinais alternam.

<ExampleBlock title="Razao negativa" text="Na PG 8, -4, 2, -1, ..., q = -1/2. Os sinais alternam e os módulos são reduzidos pela metade." />

## Soma dos termos de uma PG finita

<FormulaBlock
  name="Soma dos n primeiros termos"
  expression="S_n=a_1\frac{q^n-1}{q-1},\quad q\neq1"
  description="A fórmula elimina os termos intermediários ao comparar Sₙ com qSₙ."
  variables={[
    { label: "Sₙ", meaning: "soma dos n primeiros termos" },
    { label: "a₁", meaning: "primeiro termo" },
    { label: "q", meaning: "razao" },
    { label: "n", meaning: "quantidade de termos" }
  ]}
  example="Em 2, 6, 18, 54, temos S₄ = 2(3⁴ - 1)/(3 - 1) = 80."
  note="Se q = 1, a soma é simplesmente Sₙ = n × a₁."
  mistake="Confundir a quantidade de termos n com a posição do último termo em uma sequência recortada."
/>

## Soma de uma PG infinita

Uma soma infinita só converge quando `|q| < 1`. Nesse caso, os termos se aproximam de zero e a soma tende a um valor finito.

<FormulaBlock
  name="Soma da PG infinita convergente"
  expression="S_\infty=\frac{a_1}{1-q},\quad |q|<1"
  description="A cauda da sequência fica cada vez menor, permitindo que a soma se aproxime de um limite."
  variables={[
    { label: "S∞", meaning: "limite da soma infinita" },
    { label: "a₁", meaning: "primeiro termo" },
    { label: "q", meaning: "razao com modulo menor que 1" }
  ]}
  example="1 + 1/2 + 1/4 + ... tem soma 1/(1 - 1/2) = 2."
  note="Termos tenderem a zero é necessário; na PG, |q| < 1 garante a convergência."
  mistake="Aplicar a fórmula quando |q| é maior ou igual a 1."
/>

## Aplicações

Crescimento populacional por percentual fixo, juros compostos, depreciação e repetição de escalas são situações típicas de PG.

<ExampleBlock title="Crescimento percentual" text="Uma cultura com 500 bactérias cresce 20% por hora. O fator é q = 1,20. Após 4 horas: a₅ = 500 × 1,20⁴ = 1.036,8, considerando o instante inicial como primeiro termo." />

<TipBlock title="Percentual constante vira fator constante" text="Aumento de p% corresponde a q = 1 + p; redução de p% corresponde a q = 1 - p, com p em forma decimal." />
