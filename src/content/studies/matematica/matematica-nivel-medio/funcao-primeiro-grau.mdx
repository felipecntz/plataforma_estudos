## Interpretando os coeficientes

O coeficiente angular mede quanto `y` varia para cada unidade acrescentada a `x`:

`a = Δy/Δx`

- `a > 0`: função crescente;
- `a < 0`: função decrescente;
- quanto maior `|a|`, mais inclinada é a reta.

O coeficiente linear é `f(0) = b`, portanto o gráfico cruza o eixo y no ponto `(0, b)`.

<ExampleBlock title="Taxa de variacao" text="Na função f(x) = -2x + 5, cada aumento de 1 em x reduz f(x) em 2. A reta é decrescente e cruza o eixo y em (0, 5)." />

## Construindo o gráfico

Dois pontos distintos determinam uma reta. Um roteiro rápido é:

1. calcule `f(0) = b` para obter `(0, b)`;
2. calcule o zero para obter `(x₀, 0)`;
3. marque os pontos e trace a reta;
4. confira se a inclinação combina com o sinal de `a`.

Se `b = 0`, os dois interceptos coincidem na origem. Nesse caso, escolha outro valor de x para obter o segundo ponto.

## Estudo do sinal

Para `f(x) = ax + b`, o zero divide a reta em dois intervalos.

Se `a > 0`:

- `f(x) < 0` quando `x < x₀`;
- `f(x) = 0` quando `x = x₀`;
- `f(x) > 0` quando `x > x₀`.

Se `a < 0`, os sinais se invertem.

<TipBlock title="Use o crescimento para montar o quadro de sinais" text="Depois de encontrar o zero, observe se a reta sobe ou desce. Assim você evita decorar dois casos sem lógica." />

## Encontrando a lei por dois pontos

Se a reta passa por `(x₁, y₁)` e `(x₂, y₂)`, com `x₁ ≠ x₂`:

`a = (y₂ - y₁)/(x₂ - x₁)`

Depois, substitua um ponto em `y = ax + b` para encontrar `b`.

<ExampleBlock title="Lei a partir de dois pontos" text="A reta passa por (1, 4) e (3, 10). Então a = (10 - 4)/(3 - 1) = 3. Usando (1, 4): 4 = 3 × 1 + b, logo b = 1 e f(x) = 3x + 1." />

## Aplicação: custo e ponto de equilíbrio

Uma empresa possui custo `C(x) = 500 + 20x` e receita `R(x) = 45x`. O ponto de equilíbrio ocorre quando receita e custo são iguais:

`45x = 500 + 20x` → `25x = 500` → `x = 20`.

<WarningBlock title="Interprete os coeficientes com unidade" text="Nesse exemplo, 500 é custo fixo em reais e 20 é custo em reais por unidade. Um número sem sua unidade pode levar a uma conclusão incompleta." />
