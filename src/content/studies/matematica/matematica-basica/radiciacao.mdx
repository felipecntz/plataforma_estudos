## A ideia inversa da potência

<DefinitionBlock title="Radiciação desfaz uma potenciação" text="Extrair a raiz n-ésima de um número é procurar qual valor, elevado a n, produz o radicando." />

Assim, `√25 = 5` porque `5² = 25`, e `∛27 = 3` porque `3³ = 27`.

<FormulaBlock
  name="Definicao de raiz n-esima"
  expression="\sqrt[n]{a}=b \Longleftrightarrow b^n=a"
  description="A raiz transforma a pergunta sobre o resultado em uma pergunta sobre a base da potencia."
  variables={[
    { label: "n", meaning: "indice da raiz" },
    { label: "a", meaning: "radicando" },
    { label: "b", meaning: "raiz encontrada" }
  ]}
  example="∛64 = 4 porque 4³ = 64."
  note="Quando o indice é 2, ele normalmente não é escrito."
  mistake="Confundir √(a + b) com √a + √b; essa distribuição não vale para somas."
/>

## Quando a raiz existe nos números reais

Para índice par, o radicando precisa ser não negativo. Não existe número real cujo quadrado seja `-9`, portanto `√(-9)` não é real.

Para índice ímpar, radicandos negativos são permitidos: `∛(-8) = -2`, pois `(-2)³ = -8`.

<WarningBlock title="√25 não representa ±5" text="O simbolo √ indica a raiz quadrada principal, que é 5. Já a equação x² = 25 possui duas soluções: x = 5 e x = -5." />

## Raizes exatas e aproximadas

Uma raiz é exata quando seu resultado é inteiro ou racional fácil de representar, como `√81 = 9`. Quando não é exata, podemos manter o radical ou usar aproximação: `√2 ≈ 1,414`.

<TipBlock title="Memorize quadrados perfeitos frequentes" text="1, 4, 9, 16, 25, 36, 49, 64, 81 e 100 aceleram simplificações e estimativas." />

Também vale guardar alguns cubos perfeitos:

- `1³ = 1`, então `∛1 = 1`;
- `2³ = 8`, então `∛8 = 2`;
- `3³ = 27`, então `∛27 = 3`;
- `4³ = 64`, então `∛64 = 4`;
- `5³ = 125`, então `∛125 = 5`.

<ExampleBlock title="Raiz exata" text="√144 = 12, porque 12² = 144. A pergunta escondida é: qual número ao quadrado dá 144?" />

<ExampleBlock title="Raiz cúbica exata" text="∛125 = 5, porque 5³ = 125. Como o índice é 3, procuramos um número que multiplicado por ele mesmo três vezes forme 125." />

<ExampleBlock title="Raiz não exata" text="√20 não é inteiro. Em vez de arredondar logo, simplificamos: √20 = √(4 × 5) = 2√5." />

## Propriedades da radiciação

As propriedades servem para transformar a expressão sem mudar seu valor. A regra de ouro é observar o índice da raiz e respeitar as condições de existência nos números reais.

<FormulaBlock
  name="Raiz de um produto"
  expression="\sqrt[n]{a \cdot b}=\sqrt[n]{a}\cdot\sqrt[n]{b}"
  description="Quando o indice é o mesmo, a raiz de um produto pode ser separada em produto de raizes."
  variables={[
    { label: "n", meaning: "indice da raiz" },
    { label: "a e b", meaning: "fatores do radicando" }
  ]}
  example="√(36 × 2) = √36 × √2 = 6√2."
  note="Essa propriedade é a base da simplificação de radicais."
  mistake="Usar a mesma ideia em soma: √(a + b) não é √a + √b."
/>

<FormulaBlock
  name="Raiz de um quociente"
  expression="\sqrt[n]{\frac{a}{b}}=\frac{\sqrt[n]{a}}{\sqrt[n]{b}},\quad b\neq0"
  description="A raiz de uma divisão pode ser separada em divisão de raizes, desde que o denominador não seja zero."
  variables={[
    { label: "a", meaning: "numerador" },
    { label: "b", meaning: "denominador, sempre diferente de zero" }
  ]}
  example="√(49/25) = √49 / √25 = 7/5."
  note="Funciona muito bem quando numerador e denominador têm raizes exatas."
  mistake="Esquecer que não existe divisão por zero."
/>

<FormulaBlock
  name="Raiz de uma raiz"
  expression="\sqrt[m]{\sqrt[n]{a}}=\sqrt[m\cdot n]{a}"
  description="Quando uma raiz fica dentro de outra, os indices se multiplicam."
  variables={[
    { label: "m e n", meaning: "indices das raizes" },
    { label: "a", meaning: "radicando" }
  ]}
  example="√(∛64) = √[6]{64} = 2."
  note="Como 64 = 2⁶, a raiz sexta de 64 é 2."
  mistake="Somar os indices em vez de multiplicar."
/>

<FormulaBlock
  name="Radical como expoente fracionario"
  expression="\sqrt[n]{a^m}=a^{m/n}"
  description="O indice da raiz vira o denominador do expoente fracionario."
  variables={[
    { label: "m", meaning: "expoente do radicando" },
    { label: "n", meaning: "indice da raiz" }
  ]}
  example="√[3](x²) = x^(2/3)."
  note="Essa escrita aparece muito em funções, equações e simplificações algébricas."
  mistake="Inverter a fração: o índice fica embaixo, não em cima."
/>

<WarningBlock title="Cuidado com soma e subtração" text="A raiz distribui sobre multiplicação e divisão em condições válidas, mas não distribui sobre soma e subtração. Por exemplo, √(9 + 16) = √25 = 5, enquanto √9 + √16 = 3 + 4 = 7." />

## Simplificação de radicais

Procure dentro do radicando um fator que seja uma potência perfeita do índice.

<ExampleBlock title="Simplificando √72" text="Fatoramos 72 como 36 × 2. Como √36 = 6, temos √72 = √36 × √2 = 6√2." />

Na raiz quadrada, cada par de fatores iguais sai como um fator. Na raiz cúbica, é preciso formar trios.

- `√50 = √(25 × 2) = 5√2`;
- `∛54 = ∛(27 × 2) = 3∛2`.

<ExampleBlock title="Simplificando por fatoração prima" text="√180 = √(2² × 3² × 5). O 2² sai como 2, o 3² sai como 3 e sobra o 5 dentro da raiz: √180 = 6√5." />

<ExampleBlock title="Raiz cúbica com trio de fatores" text="∛432 = ∛(2⁴ × 3³). O 3³ sai como 3 e o 2³ sai como 2, sobrando um 2 dentro: ∛432 = 6∛2." />

<ExampleBlock title="Simplificando variável" text="√(x⁶) = x³ quando x é não negativo. Em contextos gerais, a forma mais cuidadosa é |x³|, porque raiz quadrada principal não é negativa." />

## Operações com radicais

Radicais semelhantes têm o mesmo índice e o mesmo radicando, depois de simplificados. Só eles podem ser somados diretamente:

- `2√3 + 5√3 = 7√3`;
- `√2 + √3` não pode ser reduzido a um único termo.

No produto, para índices iguais, podemos juntar ou separar os radicandos quando as condições de existência forem respeitadas: `√a × √b = √(ab)`.

<ExampleBlock title="Somando radicais depois de simplificar" text="√12 + √27 = 2√3 + 3√3 = 5√3. Antes de somar, os radicais precisaram ficar semelhantes." />

<ExampleBlock title="Produto de radicais" text="√6 × √24 = √144 = 12. Também daria para simplificar primeiro: √24 = 2√6, então √6 × 2√6 = 2 × 6 = 12." />

## Racionalização simples

Racionalizar é tirar a raiz do denominador. Isso deixa a fração em uma forma mais tradicional para cálculos algébricos.

<ExampleBlock title="Racionalizando 3/√5" text="Multiplicamos em cima e embaixo por √5: 3/√5 = (3√5)/(√5 × √5) = 3√5/5." />

<ExampleBlock title="Racionalizando 2/√3" text="2/√3 = (2√3)/(√3 × √3) = 2√3/3. A ideia é transformar o denominador em uma raiz exata." />

## Expoente fracionário

Radicais e potências são duas escritas da mesma relação:

`√[n](aᵐ) = aᵐ⁄ⁿ`

<ExampleBlock title="Expoente fracionario" text="8^(2/3) pode ser lido como (∛8)². Como ∛8 = 2, o resultado é 2² = 4." />

<ExampleBlock title="Outra leitura do expoente fracionário" text="16^(3/4) pode ser lido como (∜16)³. Como ∜16 = 2, o resultado é 2³ = 8." />

## Como pensar na hora da prova

Quando aparecer uma raiz, faça três perguntas rápidas:

1. O índice é par ou ímpar?
2. Existe potência perfeita escondida dentro do radicando?
3. Estou lidando com produto/divisão ou com soma/subtração?

Se for produto ou divisão, as propriedades ajudam bastante. Se for soma ou subtração, primeiro tente simplificar cada radical separadamente; só depois veja se eles ficaram semelhantes.

<TipBlock title="Macete de simplificação" text="Na raiz quadrada, procure 4, 9, 16, 25, 36, 49, 64, 81 ou 100 dentro do número. Em √98, por exemplo, enxergue 49 × 2 e chegue em 7√2." />
