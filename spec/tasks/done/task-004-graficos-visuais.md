# Task 004 — Exemplos visuais em Visualização de dados

## Status

- [x] Concluída em 01/11/2026

## Entrega

- Componente SVG estático para 15 tipos de gráfico, com título, pergunta, interpretação e indicação de dados demonstrativos.
- Gráficos incorporados às sete páginas do módulo: barras, colunas, agrupadas, empilhadas, linha, área, histograma, pizza, rosca, boxplot, scatter plot, bolhas, mapa de calor, treemap e cascata.
- Texto aprofundado sobre leitura, escolha, formatação, riscos de interpretação e decisões aplicadas.
- Cases de negócio documentados de Verizon, Specialized, Seattle Children’s e Microsoft, com fontes diretas.
- Gráficos acessíveis por título e descrição em SVG, com rolagem interna no celular.

## Validação

- `npm run build` concluído com 91 páginas estáticas.
- Revisão visual no Chrome em 1440 px e 390 px para barras, pizza, histograma, boxplot, dispersão, bolhas, linha, mapa de calor e cascata.
- Os gráficos permanecem dentro dos cards; no celular a rolagem horizontal fica restrita ao gráfico e é indicada ao leitor.
- Conferência de ausência de rolagem horizontal da página nas rotas revisadas.
