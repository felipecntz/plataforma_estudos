# Task 001 — Diretriz editorial e visual atualizada

## 1. Visual mais clean

A plataforma deve continuar bonita, mas com menos densidade visual.

Priorizar:

- simplicidade;
- clareza;
- navegação fácil;
- revisão rápida;
- menos elementos competindo por atenção.

Evitar:

- excesso de destaques;
- home carregada;
- páginas de estudo poluídas.

## 2. Duas visualizações por tópico

Cada tópico deve ter sempre:

- `Resumo`;
- `Mapa mental`.

Deve existir um botão claro para alternar entre essas duas visualizações.

## 3. Regra do resumo

O resumo deve ser:

- mais descritivo;
- mais aprofundado;
- lógico;
- com exemplos;
- com macetes quando fizer sentido;
- suficiente para não deixar lacunas importantes.

## 4. Regra do mapa mental

O mapa mental deve ser:

- extremamente enxuto;
- resumido;
- visual;
- direto ao essencial;
- livre para omitir detalhes secundários.

## 5. Regra de conteúdo

Os tópicos demonstrativos devem ser realmente úteis para revisão.

Exemplo esperado:

- em `Frações`, cobrir operações com frações;
- mostrar soma, subtração, multiplicação e divisão;
- incluir exemplos, macetes e erros comuns.

O mesmo princípio deve ser aplicado aos demais tópicos.
